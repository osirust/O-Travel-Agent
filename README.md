# O!Travel Agent — интеллектуальный конструктор путешествий

Проект команды **AegML** для трека «О!дин запрос» на хакатоне Островка.

Делаем агента, с которым можно собрать поездку в разговоре: выбрать маршрут, даты и отели, распределить людей по номерам. Если планы поменялись, агент должен пересчитать поездку и объяснить, что изменилось.

## Текущая версия

Есть backend, хранение поездок в PostgreSQL и простой чат для проверки. Основной frontend разрабатывается отдельно.

Сейчас работаем над уточнениями, составными запросами и сохранением пожеланий при правках. В проекте уже есть:

- история изменений, пауза и продолжение разговора;
- несколько городов, группы взрослых и детей, распределение по номерам;
- демонстрационный поиск и адаптеры внешних источников;
- проверка корзины перед тестовым оформлением.

Бронирование и оплата пока имитируются. Данные демокаталога помечены в интерфейсе.

## Запуск

Нужен Docker с Compose:

```bash
docker compose up --build -d
```

Чат откроется на [localhost:8080/debug](http://localhost:8080/debug), описание API — на [localhost:8080/docs](http://localhost:8080/docs).

Для демопримера ключи не нужны. Чтобы подключить модель и внешние источники, скопируйте `.env.example` в `.env` и заполните настройки. Если порт8080 занят, укажите `APP_PORT=8081`. Ключи остаются в локальном `.env` и не попадают в репозиторий.

## Разработка

Python, FastAPI, PostgreSQL, Docker Compose.

```bash
python -m pip install -c requirements.lock '.[dev]'
python -m pytest -q
```

Для интеграционных тестов нужна отдельная БД через `TEST_DATABASE_URL`. Тесты не должны работать с базой приложения.
