# Проверка чистого запуска

Проект поднимает свой PostgreSQL в Docker. Устанавливать и настраивать SQL-сервер на компьютере проверяющего не требуется.

Для запуска нужны Docker с Compose и свободный локальный порт. При первой сборке нужен интернет для образов и Python-пакетов.

```bash
docker compose up --build -d
```

Без `.env` и API-ключей доступны DEMO-поездка и структурированные команды. Свободный диалог требует настроенного LLM API. Для другого порта задайте `APP_PORT` в локальном `.env`; ключи в репозиторий не добавляйте.

26.10 проверена ревизия `cb0eadc` в отдельном проекте с новым volume, без личных ключей и внешних вызовов:

- Одна команда `up --build` собрала приложение и запустила новую БД; health, чат и ресурсы интерфейса открылись.
- DEMO-поездка прошла preview и имитированное оформление; повтор подтверждения вернул тот же заказ.
- В отдельной попытке на том же коде перезапуски приложения и PostgreSQL сохранили поездку, паузу, доступ и заказ.
