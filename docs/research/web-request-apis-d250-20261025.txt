Нужно продолжить подготовку O!Travel Agent для хакатона. Дата проверки — 25 октября 2026. У тебя есть прошлый контекст, но ниже свежие факты: не считай прежний план выполненной системой.

Сейчас FastAPI/PostgreSQL/Docker и собственный harness уже работают. Оригинальные106 сценариев и отдельный корпус100 диалогов сохраняются раздельно. Локальная Ollama/Qwen3.5:4b полезна для разработки, но допускает ошибки понимания. Корпус100 запускали на localhost:8083; в нём две версии runtime (57 случаев до перезапуска и43 после), поэтому единый процент не является приёмкой одной версии. Есть и независимый от LLM дефект: при contextual_slot/0 model calls отказ от смены страны показал правильный текст, но оставил старое подтверждение в контексте. Полного сырого structured extraction в старых отчётах нет, поэтому нельзя приписывать все ошибки модели или harness.

На localhost:8081 подключён Groq/qwen3.8-27b. Одна реальная проверка составной фразы «белград в сербии из москвы рано утром, детей нет, один взрослый» сохранила перечисленные факты. Следующий пользовательский «привет» получил429; точная причина не установлена, не объявляй это исчерпанием суток. У Groq публично указаны30RPM/1000RPD/8000TPM/200000TPD для этой модели; конкретные аккаунтные лимиты нужно проверять. Не делай никаких реальных обращений к нашему API или LLM-провайдерам: сейчас нужны исследование и файлы с тестами, а не исполнение.

Нужны два результата.

1. Найди дополнительные независимые LLM API с реально доступным бесплатным режимом для нашего runtime, а не только coding CLI. Предпочтительны модели, пригодные для русского разговорного понимания, извлечения нескольких изменений, function calling/JSON и многошаговых диалогов. Используй свежие официальные источники и укажи точные model_id, URL API/регистрации/ключа, цену входа/выхода, RPD/RPM/TPM/TPD или честное «не опубликовано», требования карты/пополнения/верификации, срок бесплатных кредитов, ограничения региона и совместимость структурированных ответов. Отдели проверенное по документации от требующего проверки аккаунта и от наших реально проверенных результатов. Не обещай доступ через VPN и не предлагай обходить ограничения. Выбери2–3 приоритетных кандидата, остальные перечисли с причиной более низкого приоритета.

Важные ловушки: Google для владельца сейчас недоступен. В фактическом кабинете Mistral Free написано Upgrade to activate API keys, несмотря на рекламу Free в документации; не выдавай его за уже доступный нам бесплатный API. Разные :free модели OpenRouter делят аккаунтную квоту. Свежая pricing Z.ai показывает GLM4.7-Flash/4.5-Flash Free, а GLM5.3-Flash платный. У SambaNova документация о Free расходится со страницей plans, которая просит карту/кредиты. У Cerebras текущая pricing говорит об одноразовых$5 после добавления платёжного метода,30дней. Проверь сам, это ориентиры, не готовые выводы.

2. Подготовь новый качественный набор ИЗ НЕ МЕНЕЕ250 ПОЛЬЗОВАТЕЛЬСКИХ РЕПЛИК: например50 независимых диалогов по5–8 пользовательских сообщений. Нужны связанные бытовые диалоги, похожие на реальных пользователей, а не250 одиночных анкетных фраз и не механические перестановки слов. Не копируй и не заменяй прежние106/100. Называй новый набор отдельно, например D250-001…050. После каждой пользовательской реплики укажи ожидаемое поведение, разрешённые изменения состояния и запрещённые эффекты. Не надо заранее выдумывать фактический ответ нашего агента.

Покрой разные речевые акты: справочный вопрос, обсуждение идеи, прямое изменение, ответ на предыдущий вопрос, отказ, подтверждение конкретного варианта, пауза и явное продолжение. Примеры проблем: «сербию знаешь?» не выбирает страну; в уже выбранной Сербии «белгород» может быть опечаткой Белграда с видимым пояснением, а явная Россия требует иного разбора; «минимум стоимости» не равен численному бюджету; отрицания/двойные отрицания; 100к/120тыс/общий/за человека; «я взрослый»/1/детей нет/0 с привязкой к вопросу; возраст/дата рождения ребёнка и день поездки; «завтра» при совпадении с датой заезда требует уточнения; раннее утро не означает выдуманное точное время; исправления опечаток, короткие реплики, несколько фактов сразу, изменения двух-трёх условий с сохранением остальных. Также группы/номера/несколько городов, конфликт ограничений, неопределённые ссылки «второй», история/undo, запрет бронировать, сохранение при429/сбое источника.

Зафиксируй reference clock2026-10-25T18:00:00+03:00/Europe/Moscow и полное initial_state для каждого диалога: пустой либо конкретный предзаполненный. TripState содержит origin, travelers[{id,type,age,birth_date,group_id}], groups, stays[{id,city,check_in,check_out,rooms[{id,traveler_ids}]}], legs[{id,origin,destination,departure_date,mode}], budget{amount_minor,currency,scope}, constraints и preferences. Укажи alias/ID адресного ребёнка/остановки, ожидаемые JSON-поля и значения или явную причину, почему нужен вопрос. Числа денег — integer minor units, RUB в копейках. Разные формулировки вопроса допустимы: проверять нужный slot/смысл, а не точное совпадение текста. Не требуй обязательного LLM-вызова для каждого ответа: contextual обработчик может корректно ответить без модели.

География поиска первой версии: Москва, Санкт-Петербург, Сочи, Казань, Стамбул, Анталья, Дубай. Известная география шире и не равна наличию предложений; Белград можно понимать/сохранять как направление без выдуманного каталога. Сложный пример: Казань→Стамбул→Анталья→Казань,9людей/2семьи/3номера. Численные guards реализации ещё не утверждённые продуктовые пределы. Отели LiteAPI sandbox, перелёты Duffel test, SerpApi indicative; настоящие заказы/оплаты не выполняются. DEMO/SANDBOX/LIVE_INDICATIVE/LIVE_BOOKABLE различаются. Смена требований аннулирует старые цены и согласие. После «подожди, дополню» поиск не возобновляется до явного «продолжай».

Сделай отдельные сценарии, где неожиданно правильный ответ LLM всё равно может быть испорчен harness, и опиши контрольный typed/structured ответ для независимой проверки обвязки. Для сетевых сбоев дай воспроизводимую fault-recipe, не называй её уже исполненной. Для неполного оракула отметь UNBOUND/BLOCKED, не делай PASS из одной проверки JSON.
