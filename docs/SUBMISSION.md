# Архив участия в хакатоне

O!Travel Agent разработан командой AegML для трека «О!дин запрос» Ostrovok Hackathon 2026.

Официальная сдача сохранена в отдельном репозитории организаторов: [ostrovok-hackathon-2026/aegml, тег submission](https://github.com/ostrovok-hackathon-2026/aegml/tree/submission). Этот тег фиксирует версию, переданную на проверку. Публичная копия для портфолио развивается отдельно и не изменяет официальную сдачу.

Документы задачи: [трек](https://docs.ostrovok.tech/s/0ee4d8b2-ae50-4dda-a2b5-112fcdb5398d) и [технические правила](https://docs.ostrovok.tech/s/b9e6ec5e-5ad6-4091-9c85-a48eee9b21cc).

Исторические отчёты в `docs/verification/` описывают конкретные версии и условия проверок. Их результаты не означают доступность сторонних API сегодня или полную семантическую приёмку всех диалогов.

Для запуска публичной версии используйте [README](../README.md#запуск-одной-командой) и собственные API-ключи. Учётные данные команды и зашифрованный комплект закрытой сдачи в публичную поставку не входят.
