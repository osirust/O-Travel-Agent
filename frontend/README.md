# O!Travel Studio

React + JavaScript, Vite. Согласованные landing и трёхколоночная рабочая область, интеграция с существующим FastAPI backend.

Полные инструкции: [docs/FRONTEND_REACT.md](../docs/FRONTEND_REACT.md).

```sh
npm ci
npm run dev
```

API dev-proxy по умолчанию: `http://127.0.0.1:8081`. Ключи остаются в корневом серверном `.env`.

```sh
npm test
npm run build
```
